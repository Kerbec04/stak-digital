Landing page da **STAK Digital**, especialista em SEO local e Google Meu Negócio.
No ar em [stakdigital.com.br](https://stakdigital.com.br).

## 🚀 Funcionalidades

- Página única com serviços, público atendido (negócios locais e agências parceiras),
  diferenciais e perguntas frequentes
- Formulário de diagnóstico gratuito e botão de WhatsApp
- **Pronta para buscas com IA:** o arquivo `llms.txt` descreve o negócio para buscadores baseados
  em LLMs, e o `robots.txt` libera a indexação
- Sem etapa de build e sem dependências além de Google Fonts e Font Awesome via CDN

## ⚙️ Como Visualizar

Não precisa de servidor: basta abrir o arquivo no navegador.

```bash
xdg-open index.html   # Linux
open index.html       # macOS
```
